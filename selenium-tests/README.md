# Innovation Engine - Selenium Test Suite

## JIRA Story: RBTES-1035 - SPOC Dashboard Feature

This directory contains the Selenium WebDriver test automation suite for the Innovation Engine application, specifically focusing on the SPOC Dashboard feature.

## Prerequisites

- Java 17 or higher
- Maven 3.8 or higher
- Chrome browser (or Firefox/Edge)
- Innovation Engine application running on localhost:5000

## Running Tests

### Run All Tests
```bash
cd selenium-tests
mvn clean test
```

### Run Specific Test Class
```bash
mvn test -Dtest=SPOCDashboardTest
```

### Run with Different Browser
```bash
mvn test -Dbrowser=firefox
mvn test -Dbrowser=edge
```

### Run in Non-Headless Mode
```bash
mvn test -Dheadless=false
```
